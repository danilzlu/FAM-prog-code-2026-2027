# Примеры к двум занятиям: списки и деревья (C17)

## Состав

**Лекция:**
- `lecture/floyd.[ch]`: алгоритм Флойда (проверка цикла, длина, начало цикла — последние два метода как дополнительные).
- `lecture/intlist.[ch]`: собственный инкапсулированный список `int`, `head/tail/size`, операции вставки и удаления, освобождение памяти.
- `lecture/tree.[ch]`: узел бинарного дерева, создание/удаление, три рекурсивных обхода, поиск и вставка в BST.
- `lecture/demo.c`: примеры вызова.

**Семинар:**
- `seminar/exercises.[ch]`: эталоны для написанного на доске: размер дерева, высота, проверка BST, ближайший общий предок BST, зеркальное отражение; резерв — число листьев, сумма на глубине, равенство деревьев.
- `tests/test.c`: проверки обычных и граничных случаев.

## Сборка и запуск

```sh
make
./demo
make test
make clean
```

На macOS и Linux достаточно `cc`/`clang`/`gcc` и `make`. В WSL команды те же.

## Контракты и особенности

- `IntList` — непрозрачный тип. Узлы нельзя менять извне. `list_create` возвращает `NULL` при нехватке памяти. Вставки возвращают `false` при неудаче. `list_pop_front` возвращает `false` для пустого списка и при неверных аргументах; при успехе записывает извлечённое значение в `*out`. `list_destroy(NULL)` разрешён.
- `list_size(NULL)` возвращает 0 и `list_empty(NULL)` возвращает `true` для удобства; это отдельное решение интерфейса, а не общая обязанность библиотек.
- Внутренние инварианты списка проверяются `assert`; `NDEBUG` отключает проверки. При использовании только публичного интерфейса циклы не возникают.
- `LinkNode` из модуля Флойда — **отдельный учебный тип**, позволяющий специально построить циклический список. Он не связан с закрытым `Node` из `IntList`.
- BST хранит уникальные значения `int`; повторная вставка существующего ключа ничего не меняет и возвращает `true`. При ошибке `malloc` возвращает `false`, уже созданные узлы сохраняются. Для пустого дерева корень — `NULL`.
- `tree_height` измеряется **числом узлов** на самом длинном пути: пустое дерево — 0, один узел — 1.
- `is_bst` проверяет строгий порядок (дубликаты запрещены). Реализован через inorder и предыдущий посещённый узел: без арифметики с `INT_MIN/INT_MAX`.
- `bst_lca` предполагает, что оба ключа существуют в корректном BST. Для отсутствующих ключей результат не оговорён. В тестах передаются только существующие ключи.
- `tree_mirror` сохраняет форму и количество узлов, но **обычно нарушает** свойство BST. Двойное отражение восстанавливает дерево.
- Все рекурсивные операции занимают память стека `O(h)`, где `h` — высота дерева. Для вырожденного дерева `h = O(n)`; очень глубокая рекурсия может переполнить стек.
- `tree_sum_at_depth` возвращает `long long`; вызывающий код обязан обеспечить отсутствие переполнения суммы.
