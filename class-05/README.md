
# Спецификаторы %... и запись числовых литералов

Смотрите пример в файле `vprintf.c`.


| Тип | `printf` | `scanf` |
|---|---|---|
| `int` | `%d` | `%d` |
| `unsigned int` | `%u` | `%u` |
| `long` | `%ld` | `%ld` |
| `unsigned long` | `%lu` | `%lu` |
| `long long` | `%lld` | `%lld` |
| `unsigned long long` | `%llu` | `%llu` |
| `unsigned int`, восьмерично | `%o` | `%o` |
| `unsigned int`, hex | `%x` | `%x` |
| `char` | `%c` | `%c` |
| строка | `%s` | `%s` |
| `float` | `%f` | `%f` |
| `double` | `%f` | `%lf` |
| `size_t` | `%zu` | `%zu` |
| указатель | `%p` | `%p` |
