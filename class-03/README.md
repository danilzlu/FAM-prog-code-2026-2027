# Занятие 3

На занятии обсуждали:

- форматированный вывод с помощью `printf`;
- вложенные циклы;
- массивы;
- массивы переменной длины (VLA);
- объявление, определение и вызов функций;
- возвращаемые значения и функции `void`;
- рекурсивные вызовы функций.

## Файлы

### `print.c`

Примеры форматированного вывода:

- таблица умножения с помощью вложенных циклов;
- задание ширины поля в `printf`;
- вывод времени с ведущими нулями.

### `reverse.c`

Пример решения задачи «Разворот».

Используется VLA — массив, размер которого становится известен во время выполнения программы.

### `frec.c`

Пример решения задачи «Частоты».

Показывает использование значения элемента одного массива в качестве индекса другого массива:

```c
freq[array[i]] += 1;
```

### `max.c`

Пример решения задачи «MAX».

Первый простой пример собственной функции:

```c
int max(int a, int b);
```

Показаны объявление функции, её вызов и определение.

### `factorial.c`

Основные примеры работы с функциями:

- объявление и определение;
- параметры;
- возвращаемое значение;
- функции типа `void`;
- использование результата вызова функции;
- игнорирование возвращаемого значения.

В файле также оставлен отключённый пример ошибки компиляции при попытке использовать результат `void`-функции.

### `gcd.c`

Пример решения задачи «НОД» с помощью рекурсивного алгоритма Евклида.

В этом же файле рекурсивно определён факториал как дополнительный пример рекурсивного вызова функции.

> **ISSUES**
>
> - `factorial` не используется для решения задачи и оставлен только как пример рекурсии;
> - `gcd(int a, int b)` может работать неправильно для отрицательных аргументов.
