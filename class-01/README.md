# Занятие 1

Примеры кода, которые разбирались на первом занятии.

- `hello.c` пример показывает минимальную структуру программы и вывод текста с помощью `printf`.
- `scan.c` пример ввода двух целых чисел с помощью `scanf`.
- `age.c` пример объявления, инициализации и использования переменной типа `int`.
-`clock-1.c` пример решения первой задачи домашнего контеста.
