# Примеры: поиск, сортировки и односвязный список

Исходники на C17, разделены на три модуля:

- `search/`: линейный поиск по индексу, по указателю, обобщённый поиск с компаратором, бинарный поиск.
- `sorting/`: поиск минимума, обмен значений, сортировка выбором, вставка в отсортированный префикс, сортировка вставками.
- `list/`: структура узла, печать, вставка после указанного узла, освобождение памяти.
- `main.c`: примеры вызовов и простые проверки `assert`.

## Запуск

```sh
make
./demo
```

Или без `make`:

```sh
cc -std=c17 -Wall -Wextra -Wpedantic -g -O0 main.c search/search.c sorting/sorting.c list/list.c -o demo
./demo
```

## Контракты и ограничения

- Все функции поиска по индексу возвращают `ptrdiff_t`: `-1` означает отсутствие элемента. Предполагается, что допустимые индексы массива представимы типом `ptrdiff_t`.
- Функции поиска по указателю возвращают указатель внутрь исходного массива или `NULL`. Возвращённый указатель не следует освобождать.
- `linear_search_generic` принимает размер элемента в байтах и функцию сравнения; предполагается корректный массив, `element_size > 0`, отсутствие переполнения `n * element_size`, корректные `key` и `compare`.
- Для `binary_search_index` массив **обязательно отсортирован** по неубыванию. При повторяющихся элементах может возвращаться любой подходящий индекс.
- `insert_sorted_prefix(a, k, value)` предполагает, что `a[0..k)` отсортирован и доступен элемент `a[k]` для записи. Самостоятельно память не выделяет и длину массива не меняет.
- `list_insert_after` требует указатель на существующий узел; при успешном вызове выделяет новый узел. Вставка в начало списка здесь не реализована.
- Печать и освобождение списка предполагают отсутствие циклов.

В примерах используются комментарии к инвариантам и ключевым действиям. Для полноценной библиотеки потребовались бы более подробные проверки аргументов и отдельные тесты.
