# CSVStat test bank

Структура банка тестов для лабораторной работы `csvstat`.

- `level04/` — базовые корректные таблицы только с `INT`;
- `level06/` — корректные таблицы с `INT` и `DOUBLE`;
- `level08/valid/` — корректные таблицы полной базовой спецификации CSV;
- `level08/invalid/` — некорректные CSV для проверки ошибок;
- `level09/scientific/` — тесты `--scientific`;
- `level09/multiline/` — тесты `--multiline`;
- `level09/delimiter/` — тесты `--delimiter`;
- `level09/combined/` — совместная работа параметров;
- `level10/sources/` — исходные CSV для бинарного режима и замеров производительности.

Ожидаемые результаты пока не хранятся: они будут (или не будут) сгенерированы позже эталонным решением.
