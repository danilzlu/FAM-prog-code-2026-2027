# Программирование — примеры кода

В этом репозитории собраны примеры кода с занятий по курсу «Программирование» для студентов ФПМ.

Код организован по занятиям:

```text
class-01/
class-02/
class-03/
...
```

В каждой папке находится код, который разбирался или писался на соответствующем занятии, а также `README.md` с краткими пояснениями.

## Как запустить пример

Перейдите в папку соответствующего занятия и скомпилируйте нужный файл.

### Windows

```powershell
gcc hello.c -o hello.exe
.\hello.exe
```

### macOS

```bash
clang hello.c -o hello
./hello
```

## Стиль кода

В репозитории используется единый стиль форматирования, заданный файлом `.clang-format`.

Для форматирования открытого файла в VS Code:

* Windows: `Shift + Alt + F`
* macOS: `Shift + Option + F`

В именах переменных и функций используется `snake_case`:

```c
int number_of_students;
int seconds_in_minute;
```

## Важно

Примеры в этом репозитории — учебные. Они предназначены для иллюстрации материала занятий и могут быть намеренно проще, чем код, который стоит писать в реальных проектах.

Основные материалы курса, задания и объявления доступны на [сайте курса](https://danilzlu.github.io/FAM-prog-2026-2027/).
